# 第 1 节：从零造一个小数据库

## 【本节目标】

- 搞懂"数据库"到底是个什么东西——它不是一个神秘的服务，本质就是一个文件。
- 亲手建出一张表，往里面塞进 3 条数据。

学完这节，你能指着硬盘上一个文件说："这就是我的数据库。"

---

## 【核心概念讲解】

### 为什么先讲这个

你电脑上装的 MySQL，密码今天没对上（试了 4 个都不行，日志里那个密码是打了码的，找不回来）。但不会因此白来一趟——因为你要学的**动作**只有三个：

```
建表  →  塞数据  →  查数据
```

这三个动作，SQLite 和 MySQL **几乎一模一样**。区别只在"怎么连上去"那两行代码。今天用 SQLite 跑通，等你哪天确认了 MySQL 密码，改十几行就换过去了。

### 比喻：数据库就是一本 Excel

| Excel 里的东西 | 数据库里的叫法 |
|---|---|
| 一个 .xlsx 文件 | 一个数据库（database） |
| 文件里的一个工作表（Sheet） | 一张表（table） |
| 表头的"姓名、年龄、城市" | 字段 / 列（column） |
| 其中一整行"小明 18 杭州" | 一条记录（row） |
| 你在单元格里做的筛选、排序 | 用 SQL 语句来问 |

所以"创建数据库"这件事，听起来很唬人，实际上：
- **SQLite**：建一个 `.db` 文件，完事。文件在，数据库就在。
- **MySQL**：先有个"保管员"（服务）一直开着，你的数据放在它管的仓库里，你通过网络去存取。

### 举个具体例子

我们要造一个 `shop.db`，里面有一张 `users` 表，存三个人的信息：

```
id | name | age | city
1  | 小明  | 18  | 杭州
2  | 小红  | 22  | 上海
3  | 老王  | 35  | 北京
```

`id` 是每行独一无二的编号，交给数据库自己加。

## 【动手应用】

打开你已经开着的 [database_build.py](database_build.py)（现在是空的），把下面这段**自己敲一遍**（别复制，敲一遍印象才深）：

```python
import sqlite3          # Python 自带，不用 pip 装

# 1. 连接数据库。文件不存在就自动创建一个
conn = sqlite3.connect("shop.db")

# 2. 拿一个"游标"。可以理解成一支笔，SQL 都通过它写出去
cur = conn.cursor()

# 3. 建表。IF NOT EXISTS = 表不存在才建，已存在就跳过
cur.execute("""
CREATE TABLE IF NOT EXISTS users (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT    NOT NULL,
    age  INTEGER,
    city TEXT
)
""")

# 4. 塞三条数据。问号是"占位符"，真正的值在后面元组里
cur.execute("INSERT INTO users (name, age, city) VALUES (?, ?, ?)", ("小明", 18, "杭州"))
cur.execute("INSERT INTO users (name, age, city) VALUES (?, ?, ?)", ("小红", 22, "上海"))
cur.execute("INSERT INTO users (name, age, city) VALUES (?, ?, ?)", ("老王", 35, "北京"))

# 5. 提交！不 commit，数据不会真的落进文件
conn.commit()

print("建库建表完成")
conn.close()
```

然后在终端跑：

```bash
cd /d/python/my_agent
python database_build.py
```

看到 `建库建表完成`，你的第一个数据库就诞生了。

### 顺便看一眼它长什么样

再敲一个小脚本，或者直接在终端里试试：

```bash
python -c "import sqlite3; c=sqlite3.connect('shop.db'); print(c.execute('SELECT * FROM users').fetchall())"
```

应该打印出三行元组。这就是你的数据。

### MySQL 版本长什么样（先看一眼，不用跑）

等你密码确认了，这两处就是全部要改的地方：

```python
import pymysql
conn = pymysql.connect(host="127.0.0.1", port=3306,
                       user="root", password="你的密码",
                       database="shop", charset="utf8mb4")
cur = conn.cursor()
```

SQL 语句里：
- 占位符 `?` → 要改成 `%s`
- `AUTOINCREMENT` → 要改成 `AUTO_INCREMENT`
- 而且 MySQL 得先 `CREATE DATABASE shop;` 才有库可用，SQLite 不需要这一步

## 【易错点提醒】

1. **忘记 `conn.commit()`** —— 这是新手第一坑。程序跑完看着一切正常，一关就全没了。记住：改了数据就要 commit，改了表结构（CREATE/ALTER）也要。
2. **路径踩空** —— `sqlite3.connect("shop.db")` 是相对路径，取决于你**在哪个目录下运行 python**。本节请在 `d:\python\my_agent` 目录下运行，这样 `shop.db` 会老老实实生成在项目根目录。
