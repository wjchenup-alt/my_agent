# 第 2 节：把数据查出来

## 【本节目标】

- 搞懂 `SELECT` 到底在做什么，以及 `fetchone` / `fetchall` 的区别。
- 亲手写一个脚本，把 `shop.db` 里的数据读出来，并且按条件筛。

---

## 【核心概念讲解】

### 比喻：数据库是个"点菜的窗口"

上一节你在后厨把菜做好了（数据落进了 `shop.db`）。现在你站到窗口前点菜。

- `execute("SELECT ...")` —— 你把需求告诉窗口（"我要所有人的名字和城市"）
- 窗口**不会**立刻把菜塞你手里，而是给你一张**取餐单**
- `fetchall()` —— 拿着取餐单去把**所有**菜端过来
- `fetchone()` —— 只端**一份**过来

这张"取餐单"就是**游标（cursor）**。所以顺序永远是：**先 execute，后 fetch**。

### 为什么要有"游标"这一层

你可能会问：为什么不能 `conn.execute(...)` 直接给我结果？

因为数据库返回的可能是一百万行。游标让你**一行一行地取**，取多少算多少，内存不会爆。`fetchall()` 只是"我全都要"的快捷写法。

### `SELECT` 就是一句"问话"

```sql
SELECT name, city FROM users WHERE age > 20
```

读成大白话：**从 users 这张表里，找出年龄大于 20 的人，给我他们的名字和城市。**

- `SELECT` 后面跟：你要哪些列
- `FROM` 后面跟：从哪张表
- `WHERE` 后面跟：筛什么条件（不写就是全都要）

## 【动手应用】

在 `d:\python\my_agent` 下新建 `query.py`，自己敲：

```python
import sqlite3

# 1. 连上上一节建好的库
conn = sqlite3.connect("shop.db")
cur = conn.cursor()

# 2. 查全部
cur.execute("SELECT * FROM users")
rows = cur.fetchall()          # 拿到所有行，每行是一个元组
print("一共", len(rows), "条：")
for row in rows:
    print(row)

print("-" * 30)

# 3. 按条件查：只要年龄大于 20 的
cur.execute("SELECT name, city FROM users WHERE age > ?", (20,))
for name, city in cur.fetchall():
    print(name, "住在", city)

# 4. 只取一条
cur.execute("SELECT * FROM users ORDER BY age DESC")   # 按年龄从大到小排
print("年纪最大的：", cur.fetchone())

conn.close()
```

跑起来：

```bash
cd /d/python/my_agent
python query.py
```

预期输出（中文能正常显示的话）：

```
一共 3 条：
(1, '小明', 18, '杭州')
(2, '小红', 22, '上海')
(3, '老王', 35, '北京')
------------------------------
小红 住在 上海
老王 住在 北京
年纪最大的： (3, '老王', 35, '北京')
```

### 加餐（选做）：让结果变成"字典"更好读

上面打印出来是 `(1, '小明', 18, '杭州')`，你得靠位置猜哪个是哪个。加一行配置就能变成带名字的形式：

```python
conn.row_factory = sqlite3.Row      # 加在 connect 之后、execute 之前
```

然后 `row["name"]` 就能直接用列名取值了。第 3 节我们会用到它。

## 【易错点提醒】

1. **中文显示成乱码**（比如打印出 `С��`）——这不是数据坏了，是 Windows 终端默认用 GBK 编码，跟 Python 输出的 UTF-8 对不上。解决办法：在 VSCode 终端里先敲一句 `chcp 65001` 回车，再运行脚本。**数据本身是好的**，只是显示的问题。
2. **查询忘写 `FROM`**，或者表名拼错（`user` vs `users`）——会报 `no such table`。表名是 `users`，带 s。
3. `WHERE` 后面如果传字符串，问号占位记得用元组，单个参数也要写成 `(20,)` 带逗号，不然 Python 会把它当普通数字而不是元组。
