# 学习文档标准模板

每次生成学习文档时，必须严格按照以下结构输出：

## 【本节目标】
- 用最通俗的话列出本节需要掌握的1-2个目标。
- 明确告诉用户：学完这节，你能做到什么。

## 【核心概念讲解】
- 先用一个生活化比喻解释“为什么”。
- 再给出准确定义，配一个具体例子。
- 不要堆砌术语，能用大白话就不用专业黑话。

## 【动手应用】
- 给出一个用户能亲手完成的小练习或真实场景。
- 练习必须紧扣本节概念，不能超纲。

## 【自测与思考】
- 如有需要请提供自测题，检验用户是否真正理解。
- 先给提示，不要直接给答案。

## 【易错点提醒】
- 指出本节最容易踩的1-2个坑，防止用户走弯路。

## 【下一步预告】
- 简单预告下节课讲什么，给用户一个期待。
